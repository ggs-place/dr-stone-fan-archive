# Dr. Stone Fan Archive

A responsive Dr. Stone fan website featuring season-by-season episode information in expandable cards.

The website is designed for:

- Landscape mobile devices
- Tablets in horizontal orientation
- Laptop screens
- Desktop computers

## Features

- Season-wise episode archive
- Expandable season cards
- Expand All and Collapse All controls
- Episode titles and descriptions
- Dr. Stone-inspired color palette
- Landscape-only layout
- Responsive desktop and tablet design
- Full-screen background image
- Static website with no backend or database
